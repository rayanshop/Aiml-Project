# 📊 Student Performance Predictor

A beginner-friendly **Machine Learning project** that predicts student marks based on study hours using **Linear Regression**.

## 🚀 Features

* Predicts marks based on study hours
* Uses Linear Regression
* Simple user input
* Beginner-friendly ML project

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

## ⚙️ How It Works

1. Loads the student performance data.
2. Splits the data into training and testing sets.
3. Trains a Linear Regression model.
4. Takes study hours as user input.
5. Predicts the expected marks.

## 📦 Installation

```bash
pip install pandas numpy scikit-learn
```

## ▶️ Run

```bash
python student_performance.py
```

### Example

```text
Study Hours: 6

RESULT
Study Hours    : 6.0
Predicted Marks: 70
```

## ⚠️ Note

This project is created for **learning purposes** and uses a small sample dataset, so predictions may not always be accurate.
